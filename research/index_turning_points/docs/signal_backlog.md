## 下一步建议

结论先行：目前没有任何信号适合独立判断顶底。真正值得继续留意的是“顶部风险预警、底部修复、底部确认”三类角色，而不是再寻找一个万能总分。

### 第一优先级

| 线索 | 建议角色 | 主要依据 | 关键限制 |
| --- | --- | --- | --- |
| 宽度—指数背离 | 顶部风险预警 | window 召回 54.1%，中位领先 1 日；触发后20日期末收益差七指数全部为负，平均约 −1.41% | 精确率仅14.1%，误报很多；无 FDR 发现 |
| 60日新高—新低广度底部 | 早期修复信号 | window 召回51.9%，预测召回31.6%；20日收益差七指数全部为正 | 修复前5日仍可能继续快速下探，不能直接当抄底点 |
| MA20/MA60均线宽度底部 | 底部确认信号 | MA20 window召回75.4%、滞后约2日；MA60召回71.5%、滞后约4日，20日收益差平均约+2.17% | 确认性强于预测性，通常已经错过最低点 |

最值得验证的新结构是：

```text
60日新高—新低修复
        ↓
MA20底部定位
        ↓
MA60方向确认
```

这条链条目前只是由分项结果推导出的新假设，尚未经过预冻结组合评测，不能把三个样本内最好结果直接拼成已验证信号。

### 第二优先级：作为风险状态辅助

- 涨跌停广度顶部：window召回45.5%、精确率30.2%，预测切片为26.9%/31.6%。20日走弱较一致，但触发后最大上行也更高，适合解释为“先冲高、后走弱”的延迟风险，不是立即顶部。

- 换手热度退潮：window召回47.5%、精确率32.2%，但中位滞后2日。之后最大下行和最大上行都扩大，更像波动放大提示，适合风控，不适合直接做空。

- 120/250日新高—新低分项：它们几乎都是60日信号的严重子集，不提供独立确认；更适合作为冲击严重度标签。

### 行业信号中值得观察的

- 传媒 Top1：触发后20日期末收益差在 onset/确认 × 七指数的14/14组均为负，平均约−1.37%，但尚未通过FDR。
- 房地产 Top1：window召回41.2%、精确率32.1%，中位领先2日；只有24个episode，需要时间分段复核。
- 采掘、煤炭：20日方向也较一致，但煤炭精确率约16%，且二者不能拼接。
- 国防军工、通信、有色、非银金融：这是最值得注意的“反向结果”——单行业分析中的15项全局FDR发现全部显示Top1后更强或更抗跌。未来若继续研究，应把它们改立为“风险偏好/趋势延续”假设，而不是顶部信号。

### 可以明确降级或淘汰的方向

- 涨跌停广度底部：3项局部FDR发现全部与底部修复方向相反，应淘汰。
- 新高—新低广度顶部：多数名义发现显示后续上涨更强，应淘汰顶部解释。
- 单行业 Top1 作为通用顶部信号：整体被反驳。
- 四行业 Top1：window召回94.1%，但精确率只有8.7%，而且样本从2021年末才开始；只适合作为高频市场状态基线。
- 多周期均线宽度顶部：定位较弱，短期走势多与顶部假设相反。

因此，我会把后续精力按以下顺序投入：

1. 预冻结评测“60日新高—新低修复 → MA20 → MA60”的底部状态机。
2. 单独复核宽度—指数背离的跨年份顶部风险稳定性。
3. 检验涨跌停顶部与换手热度是否能提升风险分级，而不是提升顶点预测。
4. 另立行业趋势延续研究，不再把行业Top1强行解释为顶部。

以上结论基于截至2026-08-14的离线评测，不是交易回测或投资建议。

## 模型训练

可行，而且这是比继续手工调整单信号阈值更合理的下一步。现有信号各自承担“风险、修复、确认、波动”角色，机器学习有机会学习它们的条件组合。

第一版冻结口径与实施边界见 [`ml_training_v1_memo.md`](ml_training_v1_memo.md)。

但应把它定义为全新的、预冻结的 ML 实验，不能直接用已经看过的最佳结果拼分。

### 推荐目标：两个独立评分

分别训练：

- `top_score`：未来接近顶部的程度。
- `bottom_score`：未来接近底部的程度。

二者不要强制相加等于100，因为中性时期可以都低，剧烈震荡时期也可能同时偏高。

比直接回归“距顶底几天”更稳健的方法，是训练嵌套的多期限概率：

```text
p5  = 未来0～5日进入严格顶部/底部峰瓣的概率
p10 = 未来0～10日进入的概率
p20 = 未来0～20日进入的概率

score = 100 × (0.5×p5 + 0.3×p10 + 0.2×p20)
```

上式是首次冻结的 V1/V2 公式。查看 V2 结果后实施的 V3 另立版本，使用 `0.7×p5 + 0.3×p10`，并将每次连续越阈值的有效报警限制为前 2 个交易日；具体结果和“结果知情、非前瞻”的边界见 [`ml_training_v1_memo.md`](ml_training_v1_memo.md)。

越临近转折，`p5` 理应越高，因此评分自然升高。如果 `p20` 低于预冻结门槛，就将展示评分置为0。

训练标签应以现有 `strict core lobe` 为准，不用单个最高/最低日期，因为M顶、W底和平台型区域不存在稳定的唯一转折日。`loose/window` 留作评测，避免训练和评测口径循环。

### 特征建议

第一版只使用每日连续量，不以稀疏的 `triggered=True/False` 为主：

- MA20/60/120宽度水平及1/5/10日变化；
- 宽度—指数背离及其变化；
- 60日新高—新低净广度，120/250日作为严重度；
- 涨跌停触及/封板净比例的历史分位及变化；
- 换手中位数、加权均值、极端占比的历史分位及变化；
- 数据质量、有效样本比例和仅使用历史计算的趋势特征。

完整特征集的共同起点是2012-07-05。四行业信号从2021年末才完整，单行业维度又较高，建议第一版暂不加入，避免缩短样本和增加过拟合。

### 模型从简单开始

当前只有约3400个交易日，真正独立的顶底episode远少于每日样本数，不适合直接上LSTM或Transformer。

建议比较：

1. Elastic Net逻辑回归：可解释基线。
2. 浅层 GBDT：学习“背离 + 热度退潮”“修复 + 宽度确认”等非线性交互；V1 保留 scikit-learn `GradientBoostingClassifier`，安装依赖后的 V2 另立 `shallow_xgboost`，不覆盖 V1。
3. 简单等权/规则组合：作为必须战胜的朴素基线。

如果浅层 GBDT 不能稳定战胜逻辑回归和简单组合，就没有理由增加复杂度。

### 最重要的验证约束

- 只能做 expanding walk-forward，禁止随机拆分。
- 分割边界至少 purge/embargo 20个交易日，防止未来20日标签跨越训练和验证区间。
- 标准化、缺失处理、校准和阈值都只能在训练/验证段拟合。
- 相邻高分日合并成episode，不能把连续20天当成20次独立命中。
- 阈值按固定报警预算选择，例如“每年最多若干个episode”，不能在最终测试段追求最佳收益。
- 主要指标应是：固定报警预算下的区域召回、episode精确率、中位提前量、误报次数/年和概率校准；5/10/20日OHLC及FDR继续作为独立评测。

由于截至2026-08-14的聚合结果已经被查看过，即使现在冻结2024—2026作为测试段，它也只能叫“回顾性时间外检验”，不能算完全未触碰样本。真正的前瞻证据要来自协议冻结后的新增数据。

### 我对结果的预期

- 底部评分最有希望：60日新高—新低负责早期修复，MA20/MA60负责定位和确认，角色互补比较明确。
- 顶部评分更可能成为“未来20日风险/波动评分”，而不是精确的顶部概率。宽度背离、涨跌停退潮和换手退潮共同出现时，可能提高风险分级，但未必能定位最高点。
- 最大价值可能不是显著提高命中率，而是把当前离散、容易抖动的信号转成可校准的连续状态量。

因此我赞成开展，并建议把第一版冻结为：

```text
全A严格峰瓣标签
+ 5/10/20日双方向概率
+ 连续点时特征
+ Elastic Net / 浅层 GBDT
+ expanding walk-forward
+ 固定报警预算
```

现有标签与评测边界见 [`top_bottom_region_evaluation_plan.md`](top_bottom_region_evaluation_plan.md)。
