# 顶底关系候选信号清单

状态：研究假设，尚未实现或验证。这里的“顶部/底部方向”只表示待检验假设，不代表信号有效，更不代表交易建议。

## 选择原则

1. 信号日在点时数据上计算，不使用未来成分、未来行业归属或事后修订值。
2. 先保存连续原始量，再生成离散触发，避免只留下一个不可复核的布尔值。
3. 信号方向、窗口和标准化方法在查看顶底结果前固定，不按单一指数寻优。
4. 优先选择七个目标指数可以共用、历史较长、定义透明的数据。
5. 每个信号单独评价；不在当前阶段合成总分，也不开发策略。

## P0：先完成的数据口径

第一批信号都依赖全A历史横截面。正式计算前先锁定以下规则并生成每日数据质量清单：

- 当日可见的A股上市集合与申万一级行业归属；
- 新股所需的最少历史交易记录数；
- ST、停牌、退市整理期和当日缺价的分母处理；
- 行业分类版本切换与最小有效样本数；
- 涨跌停价格按当日实际 `high_limit/low_limit` 判断，不硬编码 5%、10% 或 20%；
- 每日输出总股票数、有效股票数、各排除原因数量和行业覆盖数。

这一层应在 JQ 研究环境导出，本地只负责确定性计算和关系评估。现有通达信文件只有指数 OHLC，不能支持历史全A横截面信号。

## P1：第一批信号

| 信号 | 初始方向假设 | 连续原始量 | 初始触发方式 | 评价 |
| --- | --- | --- | --- | --- |
| 四行业 Top1 | 顶部 | 四行业宽度、名次、领先行业和并列数 | 四行业任一成为全市场宽度 Top1 | **最先实现**；用户已固定定义 |
| 多周期均线宽度 | 顶部与底部 | `close > MA20/60/120` 的股票比例 | 极高/极低水平及其变化率分别研究 | 与四行业共用价格和行业数据 |
| 宽度—指数背离 | 顶部优先 | 指数距阶段高点、宽度距自身阶段高点、二者变化差 | 指数接近新高但宽度回落或未创新高 | 比单日极值更接近“内部走弱”假设 |
| 新高—新低广度 | 顶部与底部 | 创 60/120/250 日新高和新低的股票比例及净值 | 新高萎缩检验顶部，新低扩散/衰竭分别检验底部 | 需要至少 250 日历史，样本会缩短 |
| 涨跌停广度 | 顶部与底部 | 收盘涨停数、跌停数、占比和净差 | 涨停拥挤检验顶部，跌停扩散及其衰竭检验底部 | A股特有且解释直观 |
| 换手热度 | 顶部优先 | 全A换手率中位数、市值加权均值、极高换手股票占比 | 使用只含过去数据的滚动分位数识别过热 | 需控制上市扩容和长期趋势 |

### 1. 四行业 Top1

定义已经在项目 README 固定。实现时同时保留全部行业宽度矩阵，不能只导出一个布尔值；这样可以核查排名、并列和行业样本数，也能与一般市场宽度共用数据。

### 2. 多周期均线宽度

对 `n ∈ {20, 60, 120}` 计算：

```text
breadth_ma_n(t) = 有效股票中 close(t) > MA_n(t) 的数量 / 当日有效股票数
```

同时保存原值、5/20 日变化和仅使用历史数据的滚动分位数。顶部与底部阈值先不在实现代码中写死，待数据覆盖和分布审计后一次性登记到研究配置。

### 3. 宽度—指数背离

先开发连续特征，不直接写“背离成立”的复杂规则：

```text
index_drawdown_n  = close / rolling_max(close, n) - 1
breadth_drawdown_n = breadth_ma_20 / rolling_max(breadth_ma_20, n) - 1
divergence_n       = breadth_drawdown_n - index_drawdown_n
```

优先检查 `n ∈ {60, 120}`。数值越负表示指数仍接近阶段高位，但参与上涨的股票已经减少，初始只作为顶部候选。

### 4. 新高—新低广度

分别统计当日收盘创 60、120、250 日新高或新低的股票占比，并保存：

```text
high_low_net_n = new_high_ratio_n - new_low_ratio_n
```

顶部侧重点是指数走强时新高占比是否萎缩；底部侧既检查新低极端扩散，也检查极端后的快速收缩，两者不得合并成同一个假设。

### 5. 涨跌停广度

使用当日实际涨跌停价格识别收盘封板，排除无涨跌停限制的记录。至少保存涨停/跌停数量、有效股票占比、净差和 5 日累计值。科创板、创业板、ST 和制度切换不能用统一百分比回推。

### 6. 换手热度

优先使用横截面中位数和极高换手股票占比，避免少数大市值股票支配全市场值。滚动标准化只使用当日以前的数据；不使用全样本均值和标准差。

## P2：第二批信号

| 信号 | 初始方向假设 | 建议原始量 | 排在第二批的原因 |
| --- | --- | --- | --- |
| 大小盘风险偏好 | 顶部优先 | 中证1000/沪深300、微盘股/全A 的 20/60 日相对强弱 | 易算，但与目标指数价格存在机械相关 |
| 横截面收益离散度 | 顶部与底部 | 全A日收益的中位绝对偏差、上下尾分位差 | 需先区分趋势分化与压力冲击 |
| 波动压力 | 底部优先 | 指数实现波动、振幅、极端下跌股票占比 | 波动高点常滞后价格底部，方向窗口需谨慎固定 |
| 行业集中度 | 顶部优先 | 行业宽度或行业收益的 Top1 占优程度、HHI/熵 | 可检验行情是否由少数行业维持 |

这些信号仍以关系研究为目的。大小盘相对强弱不能被表述成独立于指数价格的外生预警信号；报告中必须明确其机械关联。

## P3：数据成本或制度敏感信号

| 信号 | 可能方向 | 主要问题 |
| --- | --- | --- |
| 估值宽度 | 顶部与底部 | PE 负值、行业差异、财务数据时点和历史覆盖处理复杂 |
| 融资余额与资金流 | 顶部与底部 | 2010 年后才有数据，标的覆盖和制度变化明显 |
| 期权隐含波动率 | 底部优先 | 历史短、对应标的不统一，不能直接把海外 VIX 阈值搬到A股 |
| 新开户、IPO热度等情绪代理 | 顶部优先 | 多为周/月频，发布日期和口径变化需要单独建时间戳体系 |

P3 信号不应阻塞第一批。只有在 P1 形成稳定的数据和评估接口后，再决定是否投入。

## 推荐开发顺序

1. 建立全A点时股票池、价格、申万一级行业和数据质量表。
2. 同一批数据同时生成四行业 Top1 与 MA20/60/120 全市场宽度。
3. 在宽度序列上派生宽度背离，再补新高/新低广度。
4. 加入当日涨跌停价格和换手率，形成第一批六类信号。
5. 先完成单信号关系报告，再考虑 P2；不在本阶段做组合信号。

建议统一输出长表：

| 字段 | 含义 |
| --- | --- |
| `date` | 信号可得日期 |
| `signal_id` | 稳定信号名称 |
| `direction` | `top` / `bottom` / `undirected` |
| `raw_value` | 连续原始量 |
| `triggered` | 预先固定规则下是否触发 |
| `universe_size` | 当日股票池数量 |
| `valid_count` | 当日有效样本数 |
| `version` | 数据口径与信号定义版本 |

## 研究依据与使用边界

- [Directional-change 方法](https://doi.org/10.5018/economics-ejournal.ja.2012-36)支持按相对反转事件定义极值；本项目仍需独立验证日频A股指数上的适用性。
- [Advance–Decline Line 的早期统计检验](https://www.cambridge.org/core/journals/journal-of-financial-and-quantitative-analysis/article/abs/an-analysis-of-the-advancedecline-line-as-a-stock-market-indicator/0381B292609316D5EC5D11D2C87EA746)提醒市场宽度的领先性不能靠历史惯例假定，因此本项目把它当作待检验信号而非既定事实。
- [Baker 与 Wurgler 的投资者情绪综述](https://www.nber.org/papers/w13189)为换手和小盘敏感度提供研究背景，但不能直接证明A股顶底预测有效。
- [A股涨跌停研究](https://arxiv.org/abs/1503.03548)表明涨跌停行为具有本地市场结构特征，因此涨跌停广度值得单独研究，不能照搬无价格限制市场的定义。
- [Cboe 波动率方法说明](https://cdn.cboe.com/api/global/us_indices/governance/Volatility_Index_methodology_VIXMO_only.pdf)只用于理解隐含波动率信号的构造边界，不能把 SPX/VIX 参数直接用于A股。

这些文献只用于提出可检验假设。是否保留任何信号，只由完整样本、预先登记口径和统一顶底评价结果决定。
